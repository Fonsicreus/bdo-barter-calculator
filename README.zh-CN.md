# 黑色沙漠以物易物计算器

[English](README.md) · [Español](README.es.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · **简体中文**

算出离港前该装哪些货物、在每座岛完成兑换后船舶的载重，以及返航时能带回多少货物。这款《黑色沙漠》（Black Desert Online）非官方航线规划工具由 Satella 维护。

使用语言选择器可在英语、西班牙语、韩语、日语和简体中文之间切换。

## 可以规划什么

| 规划器功能 | 用途 |
| --- | --- |
| **单项兑换** | 计算一座岛上的同一项兑换在载重限制内可进行多少次，并查看兑换后的载重。 |
| **按阶段连续兑换** | 选择目标阶段，按每一环节的剩余兑换次数计算起始装货量，尽可能多地获得目标阶段的货物。 |
| **多项兑换** | 将相互衔接的兑换和独立兑换排进同一条航线。调整数量或移动停靠点，即可查看哪一站的载重最高。 |
| **易货品参考** | 查询物品重量、NPC 收购价、解锁航线所需的累计兑换次数，以及突发物品交换条件。 |

首次计算时，先选择船舶，输入**船舶信息**中显示的最大载重（LT），然后选择**单项兑换**。例如，某座岛的兑换比例是交出一件 1 阶段易货品、获得两件 2 阶段易货品，兑换四次就会把 400 LT 的货物换成 3,200 LT 的货物。若船上已有其他货物，兑换前后的总载重都要加上这部分重量。

## 以物易物数据

下表的基础重量和 NPC 收购价以 Pearl Abyss 于 2026 年 4 月 16 日发布的更新为准。

| 阶段 | 单件重量 | NPC 收购价 |
| --- | --- | --- |
| 1 | 100 LT | 无法出售 |
| 2 | 400 LT | 无法出售 |
| 3 | 900 LT | 1,000,000 银币 |
| 4 | 1,000 LT | 2,000,000 银币 |
| 5 | 1,000 LT | 普通：10,000,000 银币 / 大洋：25,000,000 银币 |
| 6 | 2,000 LT | 50,000,000 银币 |
| 7 | 2,000 LT | 100,000,000 银币 |

- 以游戏内该项兑换显示的数量和剩余次数为准。页面顶部的**调试**按钮可为支持此功能的兑换启用自定义比例。
- 从 0 阶段换到 1 阶段时，每完成一次兑换就获得一件 1 阶段易货品。请输入兑换次数，并将陆地材料计入**预载货物**。这些材料的重量会始终计入整条航线的估算。
- 船舶材料的重量因物品而异，能获得的乌鸦硬币数量也因兑换项目而异。出售 5 阶段货物前，请确认物品是否带有**大洋**标签。
- 复用此前获得的货物时，规划器按阶段匹配。请确认这些货物与下一项兑换要求的物品完全一致。

### 船舶载重上限

请输入**船舶信息**当前显示的最大载重（LT），其中已包含装备、船员和增益。除上述 0 阶段陆地材料外，请勿将即将交出的物品计入**预载货物**。航线规划器假定，凡是无法从前面的停靠点获得的待兑换物品，都会在首个港口装船。

启用**超载**后，只要在同一批次完成最后一座岛的整项兑换，该项兑换结束后的载重就可以超过正常上限。在港口装货时以及开始下一项兑换之前，船舶载重仍须在正常上限内。最终载重上限设为正常上限的 **150%**，仅是用于规划的暂定值。

## 船舶扩建计算器

[以物易物计算器](https://fonsicreus.github.io/bdo-barter-calculator/) · [船舶扩建计算器](https://fonsicreus.github.io/bdo-barter-calculator/ship-upgrades/)

2.0 版支持 **13 条渡口扩建路线**，覆盖巴特利帆船至四种艾裴里亚重帆船，以及公会桨帆船的扩建。选择当前船舶和目标。在「船舶装备」查看制作配方和强化需求，在「船舶扩建」查看最终交付的材料。板屋船等直接建造的船舶不在规划范围内。

- 「获取方式」显示商店单价，「购买费用」显示缺少物品的总价。乌鸦硬币估算仅计入商店价格已核实的物品，并扣除当前余额；不包含银币或其他获取途径。
- 可以记录已有装备、材料和本周还可购买的箱数。库存保存在浏览器中，切换路线不会消耗材料。
- 重帆船路线默认假设首次强化成功。打开「保底」后，每个剩余阶段均从 0 点阿戈里斯精髓开始，计入古代铁砧生效前的所有失败。记忆残片的银币费用按用户输入的价格单独计算。

数据和名称来自 [BDO Codex](https://bdocodex.com/cn/)。价格参考 [Pearl Abyss PC 亚洲服更新公告](https://blackdesert.pearlabyss.com/Asia/en-US/News/Notice/Detail?_boardNo=13225)及社区截图。请核对所在服务器的价格和购买限制。

在「船舶装备」中，每个待制作部件都有默认展开的材料明细，拥有该部件后会隐藏此明细。不同部件所需的相同材料共享库存及缺少数量。将鼠标移至获取方式标签上或点按标签，可查看每日及每周任务，并区分完成任务必得的奖励与需要选择的奖励。部件布局和材料获取指南参考了 [BDO Workshop](https://bdoworkshop.com/carrack-resource-management)；任务奖励已与 BDO Codex 核对。

## 在本地运行

安装 [Bun](https://bun.sh)，然后在项目目录中运行以下命令。打开 Vite 在终端中显示的本地地址。

```bash
bun install --frozen-lockfile
bun run dev
```

此应用使用 React、Vite、Tailwind CSS 和 Lucide。提交更改前，请运行以下检查。

```bash
bun run lint
bun test
bun run build
```

运行 `bun run preview` 可在本地预览生产构建。向 `main` 分支推送更改会触发 Pages 工作流。每次部署成功后，`dist/` 都会发布到 GitHub 为此计算器分配的地址。[部署工作流](.github/workflows/pages.yml) · [GitHub Pages 地址](https://fonsicreus.github.io/bdo-barter-calculator/)
