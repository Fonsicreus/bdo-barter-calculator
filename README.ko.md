# 검은사막 물물교환 계산기

[English](README.md) · [Español](README.es.md) · **한국어** · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

항구에서 무엇을 실을지, 각 섬에서 물물교환을 마친 뒤 화물 무게가 얼마나 되는지, 교역품을 얼마나 가져올 수 있는지 계산할 수 있습니다. Satella가 관리하는 비공식 검은사막 항로 계획 도구입니다.

언어 선택 메뉴에서 영어, 스페인어, 한국어, 일본어, 중국어 간체로 전환할 수 있습니다.

## 계획할 수 있는 항목

| 기능 | 할 수 있는 일 |
| --- | --- |
| **단일 물물교환** | 한 섬의 제안에 대해 적재 한도 내에서 몇 회까지 교환할 수 있는지 계산하고 교환 후 적재 무게를 확인합니다. |
| **단계별 연쇄 교환** | 목표 단계를 선택하면 각 구간의 남은 교환 횟수를 고려해 목표 단계 교역품을 가장 많이 얻을 수 있는 시작 수량을 계산합니다. |
| **여러 물물교환** | 서로 연결된 제안과 독립적인 제안을 한 항로에 추가합니다. 교환 수량이나 기항지 순서를 바꿔 적재 무게가 가장 커지는 지점을 확인할 수 있습니다. |
| **교역품 안내** | 아이템 무게, NPC 판매가, 항로 해금에 필요한 교환 횟수, 돌발 물물교환 조건을 확인합니다. |

처음 계산할 때는 선박을 선택하고 **선박 정보**에 표시된 최대 적재 무게(LT)를 입력한 뒤 **단일 물물교환**을 선택하세요. 예를 들어 한 섬에서 1단계 교역품 1개를 주고 2단계 교역품 2개를 받는 제안이라면, 4회 교환 시 400 LT의 교역품을 주고 3,200 LT의 교역품을 받습니다. 선박에 이미 실린 다른 화물의 무게는 두 값에 모두 더해집니다.

## 물물교환 데이터

아래 기본 무게와 NPC 판매가는 펄어비스의 2026년 4월 16일 업데이트를 기준으로 합니다.

| 단계 | 개당 무게 | NPC 판매가 |
| --- | --- | --- |
| 1 | 100 LT | 판매 불가 |
| 2 | 400 LT | 판매 불가 |
| 3 | 900 LT | 1,000,000 은화 |
| 4 | 1,000 LT | 2,000,000 은화 |
| 5 | 1,000 LT | 일반 10,000,000 은화 / 대양 25,000,000 은화 |
| 6 | 2,000 LT | 50,000,000 은화 |
| 7 | 2,000 LT | 100,000,000 은화 |

- 게임 내 각 물물교환 제안에 표시된 수량과 남은 교환 횟수를 사용하세요. 상단의 **디버그** 버튼을 누르면 지원되는 제안의 교환 비율을 직접 입력할 수 있습니다.
- 0단계 → 1단계 물물교환에서는 교환을 완료할 때마다 1단계 교역품을 1개 받습니다. 교환 횟수를 입력하고 육지 재료는 **기존 적재 화물**에 포함하세요. 재료의 무게는 항로 전체의 계산에 계속 반영됩니다.
- 선박 재료의 무게는 아이템마다 다릅니다. 획득하는 까마귀 주화 수량은 제안마다 다릅니다. 5단계 교역품을 판매하기 전에 아이템에 **대양** 표시가 있는지 확인하세요.
- 이전 기항지에서 얻은 교역품을 다시 사용할 때 항로 계획 도구는 교역품의 단계만 비교합니다. 다음 제안에서 요구하는 아이템과 정확히 일치하는지 확인하세요.

### 선박 적재 한도

장비, 선원, 버프가 반영된 현재 최대 적재 무게(LT)를 **선박 정보**에서 확인해 입력하세요. 교환에 사용할 교역품은 **기존 적재 화물**에서 제외하세요. 위에서 설명한 0단계 육지 재료는 예외입니다. 이전 기항지에서 확보하지 못하는 제공 교역품은 모두 첫 항구에서 싣는 것으로 가정합니다.

**과적**을 켜면 마지막 섬의 제안에 따른 교환을 전부 한 번에 진행할 경우 교환 후 정상 적재 한도를 초과할 수 있습니다. 항구에서 화물을 실을 때와 다음 교환을 시작하기 전에는 정상 적재 한도를 지켜야 합니다. 최종 한도(**150%**)는 항로 계획을 위한 임시 가정입니다.

## 선박 증축 계산기

[물물교환 계산기](https://fonsicreus.github.io/bdo-barter-calculator/) · [선박 증축 계산기](https://fonsicreus.github.io/bdo-barter-calculator/ship-upgrades/)

현재 선박과 증축 목표를 선택해 중범선 4종과 길드 갤리선을 포함한 나루터 증축 경로 13개를 계획할 수 있습니다. 판옥선과 같은 직접 제작은 대상이 아닙니다. **선박 장비**에서 제작식과 강화를, **선박 증축**에서 최종 납품 목록을 확인하세요. 경로를 바꿔도 이 브라우저에 저장된 보유 수량이나 강화 단계는 변경되지 않습니다.

**획득 방법**에는 개당 가격, **구매 비용**에는 부족분의 합계를 표시합니다. 필요한 까마귀 주화는 가격이 확인된 상점 구매에 한해 계산하며, 보유 잔액을 차감합니다. 중범선은 기본적으로 첫 시도 성공을 가정합니다. **고대의 모루**를 켜면 남은 단계마다 아그리스의 정수 0에서 확정 성공까지의 실패와 성공을 계산합니다. 기억의 파편 복구 비용은 보유 수량과 직접 입력한 통합 거래소 가격으로 추정합니다. [BDO Codex](https://bdocodex.com/kr/) · [펄어비스 PC 아시아 패치 노트](https://blackdesert.pearlabyss.com/Asia/en-US/News/Notice/Detail?_boardNo=13225)

제작할 부품의 재료 목록은 기본적으로 펼쳐져 있으며, 부품을 보유하면 목록이 숨겨집니다. 재료를 공유하는 부품은 보유 수량, 부족 수량과 비용을 전체 계획에서 함께 계산합니다. 획득처 표시에 마우스를 올리거나 선택하면 일일·주간 의뢰와 확정 또는 선택 보상을 볼 수 있습니다. 부품별 구성과 재료 수집 안내는 [BDO Workshop](https://bdoworkshop.com/carrack-resource-management)을 참고했습니다.

## 로컬에서 실행

[Bun](https://bun.sh)을 설치한 뒤 프로젝트 디렉터리에서 다음 명령을 실행하세요. Vite가 터미널에 표시한 로컬 주소를 브라우저에서 여세요.

```bash
bun install --frozen-lockfile
bun run dev
```

이 앱은 React, Vite, Tailwind CSS, Lucide를 사용합니다. 변경 사항을 제출하기 전에 다음 명령으로 확인하세요.

```bash
bun run lint
bun test
bun run build
```

`bun run preview`로 프로덕션 빌드를 로컬에서 확인할 수 있습니다. `main`에 푸시하면 Pages 워크플로가 실행됩니다. 배포에 성공할 때마다 GitHub가 이 계산기에 할당한 주소에 `dist/`가 게시됩니다. [배포 워크플로](.github/workflows/pages.yml) · [GitHub Pages 주소](https://fonsicreus.github.io/bdo-barter-calculator/)
