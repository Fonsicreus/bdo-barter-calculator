# 黒い砂漠 物々交換計算機

[English](README.md) · [Español](README.es.md) · [한국어](README.ko.md) · **日本語** · [简体中文](README.zh-CN.md)

港で積み込むアイテム、各島での交換後の積載重量、持ち帰れる交易品の数を計算できます。Satellaがメンテナンスしている『黒い砂漠』の非公式物々交換プランナーです。

言語セレクターで英語、スペイン語、韓国語、日本語、中国語（簡体字）を切り替えられます。

## プランナーでできること

| 機能 | できること |
| --- | --- |
| **単独交換** | ある島の交換条件で何回まで交換できるかを計算し、交換後の積載重量を確認できます。 |
| **段階別の連続交換** | 目標段階を選び、各段階の残り交換回数の範囲で、目標段階の交易品を最も多く入手できる開始数量を計算します。 |
| **複数の交換** | 前の交換で受け取った品を使う交換と、独立した交換を組み合わせられます。数量や寄港順を変えて、積載重量が最大になる地点を確認できます。 |
| **物々交換品一覧** | アイテムの重量、NPCへの売却価格、交易路の解放に必要な累積交換回数、突発物々交換の条件を確認できます。 |

初めて計算するときは、船舶を選択し、**船舶情報**に表示される最大積載重量（LT）を入力して、**単独交換**を選んでください。たとえば、ある島で1段階交易品1個を渡すと2段階交易品2個を受け取れる場合、4回交換すると400 LTの交易品が3,200 LTになります。ほかに積載済みの貨物があれば、その重量が交換前と交換後の両方に加わります。

## 物々交換データ

以下の基本重量とNPCへの売却価格は、Pearl Abyssの2026年4月16日のアップデートに基づいています。

| 段階 | 単体重量 | NPCへの売却価格 |
| --- | --- | --- |
| 1 | 100 LT | 売却不可 |
| 2 | 400 LT | 売却不可 |
| 3 | 900 LT | 1,000,000シルバー |
| 4 | 1,000 LT | 2,000,000シルバー |
| 5 | 1,000 LT | 通常：10,000,000シルバー / 大洋：25,000,000シルバー |
| 6 | 2,000 LT | 50,000,000シルバー |
| 7 | 2,000 LT | 100,000,000シルバー |

- ゲーム内で個々の交換に表示される数量と残り交換回数を入力してください。画面上部の**デバッグ**ボタンを有効にすると、対応している交換の比率を手動で入力できます。
- 0段階 → 1段階では、交換1回につき1段階交易品1個を受け取るものとして計算します。交換回数を入力し、陸地材料を**積載済み貨物**に含めてください。その重量は航路全体を通して見積もりに含まれます。
- 船舶材料の重量はアイテムごとに異なり、獲得できるカラスコインの枚数は交換ごとに変わります。5段階交易品を売却するときは、**大洋**の表記があるか確認してください。
- 前の交換で受け取った品を使うとき、プランナーは交易品の段階で照合します。次の交換で指定されたアイテムと完全に一致することを確認してください。

### 船舶の最大積載重量

装備、船員、バフを反映した現在の最大積載重量（LT）を**船舶情報**で確認し、入力してください。上で説明した0段階の陸地材料を除き、これから交換するアイテムは**積載済み貨物**に含めないでください。前の寄港地で入手できない交換用アイテムは、最初の港で積み込むものとして計算します。

**過積載**を有効にすると、最後の島で予定している交換を全回数分まとめて行う場合に限り、交換後の積載重量が通常の上限を超える計画を立てられます。港での積み込み時と、次の交換を始める前には、積載重量が通常の上限内に収まっている必要があります。最後の交換後の上限（**150%**）は、計画用の暫定値です。

## 船舶増築計算機

[物々交換計算機](https://fonsicreus.github.io/bdo-barter-calculator/) · [船舶増築計算機](https://fonsicreus.github.io/bdo-barter-calculator/ship-upgrades/)

現在の船舶と増築先を選び、重帆船4種やギルドガレー船を含む渡し場での増築13ルートを計画できます。板屋船などの直接製作は対象外です。「船舶装備」でレシピと強化を、「船舶増築」で最終納品を確認できます。ルートを変更しても、このブラウザーに保存されている所持数や強化段階は変更されません。

「入手方法」には単価、「購入費用」には不足分の合計を表示します。必要なカラスコインは価格が確認された商店購入のみを対象とし、所持残高を差し引きます。重帆船のルートでは初回成功が初期設定です。「天井」を有効にすると、残りの各段階でアグリスの精髄が0から古代の金床による確定成功に至るまでの失敗と成功を数えます。記憶の破片での修理費用は所持数と入力した統合取引所の価格から見積もります。[BDO Codex](https://bdocodex.com/jp/) · [Pearl AbyssのPCアジアパッチノート](https://blackdesert.pearlabyss.com/Asia/en-US/News/Notice/Detail?_boardNo=13225)

## ローカルで実行する

Bunをインストールし、プロジェクトのディレクトリで次のコマンドを実行してください。起動後は、Viteがターミナルに表示するローカルアドレスを開いてください。 [Bunのインストール](https://bun.sh)

```bash
bun install --frozen-lockfile
bun run dev
```

このアプリはReact、Vite、Tailwind CSS、Lucideを使用しています。変更を提出する前に、次のチェックを実行してください。

```bash
bun run lint
bun test
bun run build
```

本番用ビルドは `bun run preview` でローカル配信できます。`main` にプッシュすると、Pagesのワークフローが実行されます。デプロイが成功するたびに、GitHubがこの計算機に割り当てたアドレスで `dist/` の内容が公開されます。 [デプロイのワークフロー](.github/workflows/pages.yml) · [GitHub Pagesのアドレス](https://fonsicreus.github.io/bdo-barter-calculator/)
